NAVIX-4 — Autonomous Maze-Solving Robot

Robofest 4.0, Gujarat — National Level Competition
Jun 2024 — Jan 2025
◆ Indian Patent Published — Application No. 202521042150

Designed and built a 10×10 cm stacked autonomous robot from scratch — custom PCB, embedded firmware, sensor fusion, and two switchable maze-solving algorithms (LSRB/RSLB). The robot explores an unknown maze, records every turn as a character string, eliminates dead ends via iterative string replacement, and replays the optimized shortest path at full speed.

The system fuses three VL53L1X time-of-flight sensors (via I²C multiplexer) with a BMX160 9-axis IMU for wall-following in corridors and magnetometer heading lock in open spaces. All firmware runs on a Teensy 4.1 (ARM Cortex-M7, 600 MHz) in a single real-time loop.
