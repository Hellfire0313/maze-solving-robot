01Three Phases, One Optimal Path

The robot operates in three distinct phases: blind exploration using priority-based wall following, dead-end elimination through string rewriting, and optimized replay.

Phase 1

Explore

Enters the maze with no prior knowledge. At every junction, reads left/front/right distances and follows LSRB or RSLB priority. Every turn is recorded as a character in a path string (L, S, R, U). Wall-following PID keeps the robot centered; magnetometer heading lock takes over in open corridors.

Phase 2

Optimize

Dead-end U-turns are collapsed via iterative string replacement. LUL→S, SUR→L, SUS→U, and six more rules run in a loop until the path stabilizes — producing the shortest dead-end-free route.

Phase 3

Replay

The optimized path is executed sequentially — each character maps to a turn + forward move. No exploration overhead, no hesitation. The robot traces the ideal route at full motor speed with compass-locked heading.

02Sensor Fusion Pipeline

Three identical ToF sensors share a single I²C bus through a TCA9548A multiplexer. The BMX160 provides absolute heading for compass calibration and open-corridor navigation.

sensor-fusion.ino
// wall-following with sensor fusion
WallFollowMode mode = determineWallMode(rightDist, leftDist);

switch (mode) {
  case BOTH_WALLS:    // center between walls using differential distance
  case RIGHT_WALL:   // track right wall at target distance (130mm)
  case LEFT_WALL:    // track left wall at target distance (130mm)
  case NO_WALLS:     // fall back to BMX160 magnetometer heading lock
}

// heading correction in open corridors
float angleDiff = calculateShortestPath(currentAngle, targetAngle);
int correction = map(abs(angleDiff), 0, 180, 0, 90);

03Custom-Built, Competition-Ready

Every component fits within a 10×10cm stacked footprint on a custom PCB (NAVIX-4), designed to meet Robofest size constraints.

Teensy 4.1
ARM Cortex-M7 at 600MHz. Real-time sensor polling, motor PWM, and decision logic in a single-threaded loop under 50ms cycle time.
3× VL53L1X Time-of-Flight
Left, front, right ranging up to 4m. All share the same I²C address, resolved through a TCA9548A multiplexer at 0x70.
BMX160 9-axis IMU
Magnetometer provides absolute heading for 4-point compass calibration (N/W/S/E). Gyro and accelerometer available for future fusion.
Dual N20 motors + HW-121
Differential drive with proportional speed control. Wall-following corrections applied as differential PWM offsets for smooth centering.
